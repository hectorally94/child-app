# Home Learning Companion

A home practice companion that helps young children (ages 3–6) practice foundational school skills through short, guided, interactive activities, while keeping the parent informed.

**Core loop:** Show → Try → Observe → Help → Try again → Celebrate → Continue

**First target:** the "Write 0" lesson, end to end (parent selects lesson → child watches demo, traces, writes → parent sees progress).

- Full product requirements: [`docs/PRD.md`](docs/PRD.md)
- Project notes for AI assistants / new contributors: [`CLAUDE.md`](CLAUDE.md)

## Status

Phase 1 prototype: the "Write 0" flow works end to end in the browser (web app, data stays on the device).

## Run locally

```bash
npm install
npm run dev
```

Tests: `npm test`. Production build: `npm run build` (output in `dist/`).
